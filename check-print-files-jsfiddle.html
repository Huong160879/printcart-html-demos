HELP & GUIDANCE

Frequently asked questions

What does Check Print Files check?

It reviews file integrity, dimensions, pages, bleed, safe area, effective resolution, color, fonts, transparency and product-specific production rules.

Do I need an account?

You can try a quick check without one. An account is required to save files, connect products, use your wallet or continue through Merchant workflows.

Do basic print checks use tokens?

No. Deterministic preflight checks do not use AI tokens.

When are AI tokens required?

Tokens are used only when you confirm an AI-assisted action such as upscale, repair or automated print correction.

What happens if I run out of tokens?

Basic print checks remain available. You can still review issues, replace your file or use non-AI fixes. Tokens are required only for AI-assisted actions, and you can add them to your shared Printcart Token Wallet whenever you choose.

What does Print Ready mean?

The checked file version passed every blocking rule for the selected product, print method, print area and provider profile.

Can I fix issues in Online Design?

Yes. Your file, product and issue context can continue into Online Design and return for an automatic recheck.

Can I use the checked file directly with a Printcart product?

Yes. A Print Ready file can be attached to its product or approved for production without downloading and uploading it again.

Are my print files stored?

Temporary uploads follow the configured retention policy. Files are kept longer only when you save them to your Printcart account or project.
